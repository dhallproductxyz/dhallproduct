# Daniel Hall | Product Management Portfolio

## 🚀 Overview
This repository contains the source code for my professional product management portfolio, deployed at [dhallproduct.xyz](https://dhallproduct.xyz). It serves as a centralized hub for my case studies, highlighting my experience driving cross-functional product launches and scaling internal operational platforms.

## 🛠️ Current Tech Stack (MVP - v1.0)
* **Frontend:** Semantic HTML5, CSS3 (Responsive, mobile-first design)
* **Version Control:** Git & GitHub
* **CI/CD Pipeline:** Netlify (Automated deployments from the `main` branch)

## 🏗️ Product Roadmap
Currently executing a phased approach to the portfolio's architecture:

* **Phase 1 (Current):** MVP Launch. Built with plain HTML/CSS to prioritize rapid deployment, zero-friction UX, and immediate availability for stakeholder review.
* **Phase 2 (Upcoming):** Tech Debt Reduction & Scalability. 
  * Migrate the architecture to a Static Site Generator.
  * Implement DRY (Don't Repeat Yourself) principles by creating reusable UI components (headers, footers, navigation).
  * Separate content from presentation by migrating case study copy into Markdown (`.md`) files for faster future iterations.

## 💡 Build Philosophy
I chose to build this portfolio from scratch, navigating the command line and setting up my own deployment pipelines, to gain hands-on, empathetic experience with modern web development workflows and CI/CD architecture.
